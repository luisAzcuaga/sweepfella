# Sweepfella

A small, free Windows cleaner — a CCleaner alternative without ads, telemetry or a background monitor.
One ~200 KB executable, no installer, no runtime to download: it runs on the .NET Framework that ships with Windows 10/11.

## Features

**Cleanup**
Temporary files, Recycle Bin, error reports and crash dumps, thumbnail cache, DirectX/GPU shader cache and browser caches
(Chrome, Edge, Brave, Vivaldi, Opera, Firefox — cache only: history, cookies and passwords are never touched).
Analyze first, confirm, then clean. Temporary files from the last 24 hours are kept by default so running installers don't break.
Freed space is counted towards a lifetime total; for uninstalls it's measured as the free space each drive actually
gained, so it reflects the real size rather than the size the program claims.

**Programs**
An uninstaller that explains what each entry is. For Visual C++ and .NET runtimes it goes further:

- Detects runtimes **superseded** by a newer version of the same family (e.g. VC++ 2013 12.0.30501 → 12.0.40664;
  every VC++ 2015–2022 entry is covered by the latest v14 runtime).
- **Find dependencies** reads the import table of every installed `.exe`/`.dll` (and every `*.runtimeconfig.json`)
  to show which programs actually use each runtime, per architecture, ignoring programs that bundle their own copy.
- Flags .NET versions that are out of support.

**Leftovers**
Finds folders in AppData (Roaming, Local, LocalLow), ProgramData, Program Files and your Steam libraries that no
installed program, service, running process, shortcut or driver accounts for — what uninstallers leave behind,
including the mods and shader caches of games you've uninstalled from Steam. Nothing is pre-selected, recently
modified folders are flagged, and deleted folders go to the Recycle Bin. Folders you mark as ignored never show up again.

- Select a folder to see **clues** about it: programs running from it, the publisher of the files inside, whether it
  only holds caches or logs, Unity game data (which may include saved games), the largest items and the latest change.
- **Show folders in use** lists every other folder with who it belongs to and how that's known — e.g.
  *"Comfy Desktop includes uv.exe"* or *"Folder of Steam"*. Those can be opened and inspected, never deleted from Sweepfella.

## Portable, no traces

Sweepfella never installs anything and keeps no data outside its own folder. The only file it may create is
`Sweepfella.ini`, next to `Sweepfella.exe`, and only once you change something (language, window size, ignored
folders) or free some space. Deleting both files removes Sweepfella completely. Give it its own folder, such as
`Documents\Sweepfella`; in a read-only folder like Program Files it still works, it just can't remember anything.

The About dialog shows where the settings live, how much space Sweepfella has freed so far, and a
*Delete my data and exit* button.

## Safety

- Nothing is deleted without a confirmation listing exactly what will go.
- Symlinks and junctions are never followed.
- A path guard refuses to empty critical folders (Windows, user profile, AppData roots, Program Files…) even if a path is miscomputed.
- Runs without admin rights; features that need them say so and offer to restart elevated.

## Languages

English (default) and Spanish, switchable from the window. Translations live in [`lang/`](lang) as plain
`key = text` files embedded in the executable; to add a language, copy `lang/en.txt`, translate it and rebuild.
Missing keys fall back to English.

## Building

Sweepfella is compiled with the C# compiler included in Windows (`csc.exe` from .NET Framework 4.x), so there is nothing to install.
From WSL:

```sh
./build.sh            # bin/Sweepfella.exe
./build.sh --console  # bin/Sweepfella-console.exe — same app with a console, for the read-only report modes below
```

Read-only reports (they never delete anything):

```sh
Sweepfella-console.exe --analyze     # what the Cleanup tab would free
Sweepfella-console.exe --programs    # installed programs, runtime status and dependencies
Sweepfella-console.exe --leftovers   # leftover folders
Sweepfella-console.exe --inspect <folder>   # clues about who owns a folder
```

The icon is generated by `tools/make_icon.py` (pure Python, no dependencies).
